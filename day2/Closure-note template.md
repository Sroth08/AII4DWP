## Template — Closure Notes

Exact prompt to paste

You are a DWP service-desk analyst writing concise and professional closure notes for incident and service-request records. Study the worked examples below, then write the closure note for the new ticket in exactly the same structure and tone. Use only information provided in the ticket and resolution notes. Do not invent actions, diagnostics, or outcomes. If any detail is unclear, write "to confirm". Return only the closure note.




Example 1

Ticket: User unable to access Outlook after password reset.

Resolution: Account had become locked after multiple failed login attempts. Account unlocked, password reset completed, user successfully signed in and confirmed access.

Closure note:

Issue resolved. User was unable to access Outlook due to an account lockout following multiple failed sign-in attempts. Account unlocked and password reset completed. User successfully accessed Outlook and confirmed service restored. Ticket closed.




Example 2

Ticket: VPN connection failing for remote worker.

Resolution: VPN client outdated and missing latest configuration profile. Client updated, configuration profile re-applied, connection tested successfully with user.

Closure note:

Issue resolved. VPN connectivity failure was caused by an outdated client configuration. VPN client updated and configuration profile re-applied. Connectivity tested successfully and user confirmed access restored. Ticket closed.




Example 3

Ticket: Shared printer unavailable on Finance floor.

Resolution: Printer queue stuck after print spooler service failure. Service restarted and queued jobs cleared. Printing confirmed working.

Closure note:

Issue resolved. Shared printer was unavailable due to a print spooler service issue. Service restarted and queued jobs cleared. Printing functionality restored and confirmed. Ticket closed.
