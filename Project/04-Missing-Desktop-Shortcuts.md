# Missing Desktop Shortcuts

## Scope of this issue
- Reported symptom: One user says their desktop shortcuts vanished.
- Known timing: Reported Monday morning in the same incident message.
- Known environment: Floor 6 Legal Department, Windows 11, Intune managed.

## Symptom
A user reports missing desktop shortcuts.

## Potential business impact
Reduced user productivity and possible inability to quickly launch required applications or files.

## Severity
Medium.

## Could this represent a security incident?
Not by itself. It is currently a user environment issue unless further evidence suggests unauthorized change or broader data impact.

## May this be related to the Friday application deployment?
Possible, but unproven. A recent application or configuration change could affect shortcuts, but there is no confirming evidence yet.

## First check
Confirm whether the shortcuts are missing for one user only or multiple users on the floor.

## Why that check comes first
This determines whether the issue is isolated user impact or part of a broader configuration or profile problem.

## Evidence expected
- Whether other users report the same symptom
- Whether the shortcuts are missing entirely or only not visible to the user
- Whether the user can still open the expected applications another way

## Escalation trigger
Escalate if multiple users share the same desktop shortcut loss or if the issue is found to coincide with broader profile or shell changes.
