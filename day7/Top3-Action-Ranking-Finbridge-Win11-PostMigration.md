# Top 3 Themes to Act On Today (Volume + Impact Weighted)

Date: 2026-08-12
Source: 50 post-migration end-user comments
Method: Severity-first ranking (Blocker before Friction/Minor), with volume used only as a secondary tie-breaker among same-severity themes.

## 1) AVD sign-in failures and account lockouts (count: 7)
Why it ranks here:
- Highest urgency because affected users cannot start work at all (Blocker).
- Largest blocker cluster by volume, indicating widespread access instability at the identity/session entry point.
- Directly stops productivity from the first minute of the workday.
Manager sentence:
- "Our top issue today is AVD sign-in and lockouts (7 reports): it is both high-volume and a hard blocker, so users cannot begin work until this is stabilized."

## 2) Shared drive access denied (S:/Finance) (count: 3)
Why it ranks here:
- Blocker impact: users cannot access core finance shared storage needed for month-end reporting.
- Business-critical process dependency (finance operations) elevates priority despite lower volume.
- Severity overrides count; this remains above any Friction theme and is prioritized ahead of other blockers with less role-critical process coupling.
Manager sentence:
- "Shared drive access denial on S:/Finance (3 reports) is priority two because it blocks core finance operations and immediate reporting deliverables."

## 3) OneDrive missing files and sync uncertainty (count: 4)
Why it ranks here:
- Blocker impact: users report missing required files for meetings and end-of-day deliverables.
- Strong urgency and business risk, but slightly less centralized than shared-drive finance dependency.
- Still clearly prioritized above all Friction/Minor themes due to inability to access required working files.
Manager sentence:
- "OneDrive missing-file incidents (4 reports) are priority three because they remain a blocker to document-dependent work and near-term deadlines."

## Note on non-top themes
- Floor 3 printer mapping (count: 6, Friction) is high volume but was placed below blocker themes because users can still work through alternatives (for example, printing from another floor).
